# Versioning and Stability

Current project version:

```text
13.0.11
```

## Target Versions

- Minecraft `1.21.1`
- Java `21`
- Fabric Loader `0.16.14`
- Fabric API `0.116.6+1.21.1`
- NeoForge `21.1.219`

LimLib currently builds for Fabric and NeoForge. There is no Quilt module or Quilt metadata.

## Dependency Versions

LimLib does not currently document a compatibility guarantee between releases. Dependent mods should pin an exact LimLib version until a broader compatibility policy is established.
